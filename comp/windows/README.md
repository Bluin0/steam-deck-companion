# 🖥️ Compilador: Servidor PC Windows

### 📌 ¿Qué genera?
Genera el archivo **`dist/windows/SteamDeckCompanionServer.exe`**.

### ⚙️ Requisitos para compilar:
- Sistema Operativo: **Windows 10 o Windows 11**.
- Python 3.10+ instalado y agregado al PATH.

### 🚀 Cómo compilar:
Haz **doble clic en `build_server.bat`**.

---

### 🎮 Cómo lo usa el usuario final:
1. El usuario se descarga `SteamDeckCompanionServer.exe` desde GitHub Releases.
2. Hace **doble clic en `SteamDeckCompanionServer.exe`** para jugar (no necesita consolas ni instalar Python).
